# MoE Test Scripts

Custom MoE test scripts for DeepSeek-V3-Lite and related MoE workflows.

## Layout

```
moe_test_script/
├── README.md             — this file
├── gen_fake_prompts.py   — generate ./prompts.txt (shared input for EPLB tests)
├── agg/                  — aggregated serving tests (LLM API spawns workers in one process)
│   ├── README.md
│   ├── test_dsv3lite.py                   — baseline
│   ├── test_dsv3lite_dtp.py               — Attention DP + MoE TP
│   ├── test_dsv3lite_tep.py               — Attention TP variant
│   ├── test_dsv3lite_offline_eplb.py      — Offline EPLB (3-stage workflow)
│   └── test_dsv3lite_online_eplb.py       — Online EPLB (dynamic placement)
└── disagg/               — disaggregated serving tests (separate ctx + gen + router)
    ├── README.md
    ├── ctx_config.yaml                    — context (prefill) worker config
    ├── gen_config.yaml                    — generation (decode) worker config
    ├── disagg_server.yaml                 — router config (ctx/gen URLs)
    ├── launch.sh                          — start ctx + gen + router
    ├── shutdown.sh                        — stop all 3
    └── send_request.sh                    — curl a test prompt
```

## Runtime artifacts (stay at TRT-LLM root)

The following files are produced/consumed by the scripts using relative
`./` paths, so they live at the TRT-LLM root (where you `cd` before running):

- `prompts.txt` — input prompts (generated by `gen_fake_prompts.py`)
- `expert_statistic/` — runtime statistic dumps (Stage 1 of offline EPLB)
- `moe_load_balancer.yaml` — placement config (Stage 2 of offline EPLB)
- `stage{1,2,3}.log`, `online_stage1.log` — captured logs

## Running

**Always run from the TRT-LLM root.** Examples:

```bash
cd /workspace/TensorRT-LLM   # root checkout

# Generate prompts (writes ./prompts.txt)
python moe_test_script/gen_fake_prompts.py

# Baseline
python moe_test_script/agg/test_dsv3lite.py

# Online EPLB
PROMPTS_FILE=./prompts.txt MAX_TOKENS=128 \
python moe_test_script/agg/test_dsv3lite_online_eplb.py
```

See `agg/README.md` for the full offline EPLB 3-stage workflow.
